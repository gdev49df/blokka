# blokka

блочный конструктор сайтов в духе tilda. работает целиком в браузере, без сервера, поэтому хостится на github pages.

## что умеет

- 8 блоков: обложка, о нас, услуги и цены, галерея, отзывы, вопросы и ответы, призыв к действию, контакты
- блоки можно добавлять, дублировать, удалять и менять местами (стрелки или перетаскивание за «⋮⋮»)
- живое превью, переключатель пк / телефон; клик по блоку в превью открывает его редактор
- фото загружаются с компьютера (сжимаются в браузере) или подставляются ссылкой
- 4 темы и свой акцентный цвет
- 4 готовых шаблона: клиника, школа, клуб, кафе
- контакты один раз на вкладке «сайт», кнопки ведут в whatsapp / telegram / на звонок
- проект сохраняется в браузере автоматически, а также в json-файл
- «скачать сайт (zip)» отдаёт готовый `index.html` с папкой `img/`

## запуск на github pages

1. залей `index.html`, `style.css`, `app.js` в репозиторий
2. settings → pages → deploy from a branch → `main` / root
3. конструктор откроется на `https://<аккаунт>.github.io/blokka/`

## как отдать сайт клиенту

1. собери сайт, нажми «скачать сайт (zip)»
2. распакуй в новый репозиторий клиента, включи pages
3. свой домен: settings → pages → custom domain (+ cname у регистратора)

## как добавить новый блок

в `app.js`: описание полей в объекте `BLOCKS` и функция отрисовки в `RENDER` с тем же ключом. при необходимости стили в `siteCSS`.

## идеи дальше
