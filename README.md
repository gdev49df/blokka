# blokka

блочный конструктор сайтов по идее tilda. работает целиком в браузере, без сервера, поэтому хостится на github pages.

## идеи tilda, которые перенесены

- **сайт из готовых блоков.** каталог из 17 блоков с вариантами дизайна (всего 27 видов), у каждого живое мини-превью. категории: обложка, о нас и текст, услуги и цены, доверие, связь.
- **правка прямо на странице.** кликни по тексту в превью и печатай. клик по фото открывает выбор файла. при наведении на блок появляется панель (выше, ниже, дублировать, удалить), а между блоками кнопка «＋ блок».
- **настройки блока.** вид (вариант), фон, отступы, выравнивание, скрыть блок.
- **глобальные стили.** тема, акцентный цвет, цвет фона и текста, шрифты заголовков и текста (google fonts), форма и вид кнопок, кнопка в шапке.
- **форма заявки.** посетитель заполняет имя и телефон, открывается whatsapp с готовым сообщением.
- **seo и соцсети.** title, description, картинка для превью, иконка вкладки.
- **шаблоны по нишам.** клиника, школа, клуб, кафе.
- **экспорт.** «скачать сайт (zip)» отдаёт `index.html` и папку `img/` с фото. проект сохраняется в браузере и в json.

## блоки

обложка (3 вида), о нас (2), текст, преимущества (2), услуги и цены (2), тарифы, этапы работы, цифры, команда, галерея (2), отзывы (2), вопросы и ответы, форма заявки (2), призыв к действию (2), контакты (2), карта, видео.

## запуск на github pages

1. залей `index.html`, `style.css`, `blocks.js`, `app.js` в репозиторий
2. settings → pages → deploy from a branch → `main` / root
3. конструктор откроется на `https://<аккаунт>.github.io/blokka/`

## как отдать сайт клиенту

1. собери сайт, нажми «скачать сайт (zip)»
2. распакуй в новый репозиторий клиента, включи pages
3. свой домен: settings → pages → custom domain (+ cname у регистратора)

## как добавить новый блок

в `blocks.js`: описание в объекте `BLOCKS` (поля, варианты, значения по умолчанию), функция отрисовки в `RENDER` с тем же ключом и стили в `BASE_CSS`. каталог, панель и превью подхватят блок сами.
