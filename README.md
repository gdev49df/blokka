# blokka

статичный конструктор сайтов для github pages: выбираешь шаблон, заполняешь форму, смотришь живое превью и скачиваешь готовый сайт (zip).

## запуск на github pages

1. создай репозиторий (например `blokka`) и залей `index.html`, `style.css`, `app.js`
2. settings → pages → deploy from a branch → `main` / root
3. конструктор откроется на `https://<аккаунт>.github.io/blokka/`

## как отдать сайт клиенту

1. заполни форму, нажми «скачать сайт (zip)»
2. распакуй в новый репозиторий клиента, включи pages
3. свой домен: settings → pages → custom domain (+ cname у регистратора)

## шаблоны

клиника, школа/курсы, клуб/игры, кафе. новые добавляются в объект `TEMPLATES` в `app.js` (цвета, радиус, тексты по умолчанию).

## идеи для следующих версий

- публикация в github прямо из браузера (через oauth/токен)
- галерея фото, отзывы, блок «команда»
- мультистраничные сайты
- казахский язык, переключатель рус/қаз
- платные шаблоны и админка с подпиской (нужен бэкенд, например cloudflare workers + d1)
